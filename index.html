What is this?

A grid of 32,400 programs, 64 bytes each, that starts as pure random noise. Every epoch each program is glued to a random neighbour, the 128 bytes are run as code in a ten-instruction language, and the result is cut in half again. There is no goal and no reward, and no replicator is planted.

Sooner or later, programs that copy themselves appear anyway and take over. The first ones are usually fragile and die out. This page detects them by testing whether a program really rebuilds itself on inert tape, never by what it looks like.

Based on Computational Life (Agüera y Arcas et al., 2024). Every universe is fully determined by its seed, so a shared link replays the same history. Source on GitHub
